🚀 ÉTAPES DE DÉMARRAGE

ÉTAPE 1: Installer
  $ pip install streamlit pillow numpy pandas matplotlib opencv-python-headless

ÉTAPE 2: Lancer
  $ cd rice-disease-rna-cv
  $ streamlit run src/app.py

ÉTAPE 3: Accéder
  → Ouvrir http://localhost:8501 dans le navigateur

ÉTAPE 4: Tester
  → Télécharger une image de feuille de riz
  → Consulter le diagnostic
  → Lire les recommandations
